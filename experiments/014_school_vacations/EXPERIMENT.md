# 014_school_vacations — vinterferie + efterårsferie damp groups

## Hypothesis

013's bias landscape shows the summer signature 011 erased, twice more,
at exactly the Danish school vacations: February swings +0.11/+0.15 →
−0.08/−0.13 around vinterferie (ISO weeks 7–8), October swings +0.07 →
−0.12/−0.16 around efterårsferie (ISO week 42). Same cause, same fix.

## Mechanism

Two more ISO-week damp groups in the ordered list: `win_wk7/8` (base =
28 days before week-7 Monday) and `aut_wk41/42/43` (base = before
week-41 Monday; shoulder weeks learn ≈1 if only week 42 dips). The
runup group moves last so its pre-BF base deflates week-43 days.
Factors apply to targets and as level-window deflation, as always.
One mechanism vs 013.

## Expected behavior

The four February cutoffs and Oct-09/23/30 biases shrink in both
directions; everything outside those windows byte-identical. Shoulder
weeks (41, 43) learning ≈1 would confirm the dip is week-42-only.

- Dec-18 residual (+0.20), Nov event-week noise (~0.27–0.29, bias ≈0).
